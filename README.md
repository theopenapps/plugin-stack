# plugin-stack

**You built the plugin. Now get it picked.**

Agent skills for AI plugins: ChatGPT apps, Claude plugins and connectors, Cursor plugins and MCP servers. They will run on live store data from [OpenApps](https://theopenapps.com), which tracks about 29,000 listings across six stores and the MCP servers they link to, in 48 ChatGPT countries, every day.

There are no skills here yet. Watch the repo to see the first ones land.
